A — Fondo suave + borde coloreado

Fondo muy sutil (~8% opacidad) + borde izquierdo prominente (4px) + nombre del profesional en su color. Legible, no abruma. Recomendado para muchas citas.

B — Bloque sólido (Google Calendar)

Color sólido del profesional como fondo, texto blanco. Máximo impacto visual, diferenciación instantánea. Puede verse "pesado" con muchas citas. Más impacto, menos lectura.

C — Header coloreado + cuerpo blanco

Solo el header del bloque tiene el color del profesional (sólido), el cuerpo queda en blanco para máxima legibilidad. Equilibrio entre impacto y claridad. El más legible con mucha info.

💡 Mi recomendación: Opción A — combina bien con el diseño actual y escala mejor con calendarios densos.
